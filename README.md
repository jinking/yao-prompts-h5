# Yao Prompts H5

Yao Prompts 是一个开源的 AI 提示词目录，旨在提供一个优雅、快速、响应式的 H5 界面，用于检索、预览和复制提示词。

该项目基于 `yaojingang/yao-open-prompts` 的内容构建，并采用现代化的前端技术进行了重构。

### ✨ 特性

- **赛博科技风设计**：采用磨砂玻璃效果（Glassmorphism）和深色模式。
- **极致响应式**：完美适配手机浏览器，支持丝滑的滑动和过渡动画。
- **实时检索**：支持按分类过滤和关键词实时搜索。
- **一键复制**：提供一键复制 Prompt 正文的功能，方便快速使用。
- **本地收藏**：基于浏览器缓存实现收藏功能，无需后端支持。

### 🚀 技术栈

- **Core**: React 18
- **Build Tool**: Vite
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Cyber Theme)

### 🛠️ 开发与部署

#### 1. 安装依赖
```bash
npm install
```

#### 2. 本地开发
```bash
npm run dev
```

#### 3. 生产构建
```bash
npm run build
```

#### 4. 部署到 GitHub Pages
```bash
npm run deploy
```
